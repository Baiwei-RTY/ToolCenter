# ToolCenter 发布版

双击 `ToolCenter.exe` 即可打开 ToolCenter。该目录是项目今后唯一的默认发布目录；后续正式构建会覆盖同名程序、校验值和版本信息，不会创建按版本号命名的子文件夹。

## 内置插件

- 音频设备切换：查看并切换 Windows 默认音频输出设备；
- HDR 开关：选择目标显示器，查看并切换 Windows HDR 状态；
- 桌面便签：编辑独立标题、正文和清单，支持清单拖动排序与分割线高度调节；
- 番茄钟：提供可自定义的专注与休息倒计时，支持暂停、继续、重置和多实例独立保存；
- 市场行情：查看股票、外汇和数字资产价格，支持折线图/K 线图、时间范围切换、滚轮缩放和按住拖动平移。

系统能力首次使用时会显示权限说明。HDR 操作只影响小组件中当前选择的显示器。

桌面便签未锁定时，可以按住顶部区域移动，也可以拖动边缘或四角缩放；锁定后不能移动或缩放。便签内容、清单、位置和自定义尺寸均保存在本机。

番茄钟默认使用 25 分钟专注和 5 分钟休息。专注结束时会播放提示音并自动开始休息；休息结束时会再次播放提示音并停下，等待开始下一轮专注。

市场行情使用公开免费接口。部分数据源可能需要用户自己的免费 API Key；凭据由 Windows 凭据管理器保存，不会写入发布目录。行情数据仅供信息展示，不应作为下单依据。

## 完整性校验

`ToolCenter.exe.sha256` 保存当前程序的 SHA-256。可在本目录运行：

```powershell
Get-FileHash -Algorithm SHA256 .\ToolCenter.exe
```

计算结果应与校验文件及 `版本信息.json` 中的 `sha256` 一致。

## 更新发布程序

在项目根目录运行：

```powershell
.\toolcenter.cmd release-build
```

该命令会完成全量检查、构建，并覆盖本目录中的 `ToolCenter.exe`、校验值和版本信息。

## 当前发布边界

当前文件是 Windows x64 便携式开发发布版，尚未提供安装器、代码签名和自动更新。不要加载来源不明的插件源码；发布程序只包含随项目构建并通过校验的第一方插件。
