# 暖纸便签

运行在 ToolCenter 共享 Widget Host 中的轻量桌面便签。正式界面采用独立的暖白纸张视觉，不沿用启动器的紫色卡片结构；标题、正文、清单和保存状态集中在一张便签内。

## 当前功能

- 标题可单独编辑，默认标题为“本周安排”；
- 正文自动保存；
- 添加、完成、取消完成和删除清单项；
- 按住清单项拖动调整顺序，也可使用 `Alt + ↑/↓` 完成键盘排序；
- 拖动正文与清单之间的分割线调整上下区域高度，也可使用方向键、`Home` 和 `End` 调整；
- 小组件未锁定时，可按住便签顶部圆角边框的中段拖动整个便签；
- 支持 Small 260×160、Medium 360×220、Wide 520×220 三档尺寸；
- 标题、清单、添加入口与保存状态按三档比例校准：Small 为 12/10/10/9 px，Medium 为 14.5/11/10.5/10 px，Wide 为 16/12/12/11 px；正文字号保持原值；
- 每个 Widget 实例独立保存标题、正文、分割位置和清单；
- 提供加载、保存中、已保存、保存失败和重试状态；
- 支持键盘操作、可见标签、焦点轮廓和 Reduced Motion。

## 明确不做

- 不提供富文本、Markdown、附件、图片或云同步；
- 不提供提醒、系统通知、全局快捷键或后台任务；
- 不在多个 Widget 实例之间共享内容；
- 不提供历史版本、已删除项目恢复或多人协作；
- 不创建独立窗口、WebView、Tauri 应用或后台进程。

## 数据兼容与隐私

插件只通过 `context.storage` 保存本地 JSON，不访问网络、文件系统、剪贴板或其他系统能力。

- 存储 key：`widget.<instanceId>.v1`；为兼容旧数据保留原 key；
- 当前数据结构：`schemaVersion: 2`；
- 旧版 `schemaVersion: 1` 的正文会自动迁移到新版 `body`，并补上默认标题与分割位置；
- 单个实例正文上限：4,000 字符；
- 单个实例清单上限：50 项；
- 单项清单上限：120 字符。

数据由宿主按插件 ID 隔离，`instanceId` 进一步隔离不同小组件。日志只记录操作类型、实例 ID 和错误信息，不记录标题、正文或清单内容。

## 懒加载与资源释放

- Manifest 只静态声明入口，Widget 组件通过动态 `import()` 加载；
- 未创建或未显示 Widget 时不加载业务组件；
- 仅使用一次性防抖保存计时器，不创建 `setInterval`、Scheduler 或系统监听；
- 组件卸载时清理待执行计时器，并尝试提交最后一次尚未排队的修改。

## 运行与测试

在项目根目录执行：

```powershell
corepack pnpm --filter @tool-center/plugin-sticky-notes typecheck
corepack pnpm --filter @tool-center/plugin-sticky-notes test
.\toolcenter.cmd verify
.\toolcenter.cmd plugin-dev
```

桌面验收至少检查：

1. 创建便签后，标题、正文和清单位于同一张暖纸便签中；
2. 标题与正文可独立修改，重新启动后能够恢复；
3. 添加、完成、取消完成和删除清单项正常；
4. 鼠标拖动与 `Alt + ↑/↓` 都能改变清单顺序并持久化；
5. 鼠标拖动分割线与键盘调整都能改变上下区域高度并持久化；
6. 未锁定时按住便签顶部边缘可以移动整个便签，锁定后顶部拖动热区失效；
7. Small、Medium、Wide 均无横向溢出，内容较多时清单可滚动；
8. 两个实例的数据互不串扰；
9. 保存失败时显示错误并可以重试；
10. 插件禁用或 Widget 删除后没有残留计时器；
11. 鼠标移出便签或窗口失去焦点后，四个圆角仍保持不变，不出现直角闪变。

## 已知限制

- 浏览器 Memory Host 刷新后不会保留数据，持久化验收必须在真实 ToolCenter Tauri 桌面应用中进行；
- 当前版本不提供已删除清单项恢复；
- Small 尺寸会优先保证编辑与操作可用，较长清单需要滚轮浏览。
