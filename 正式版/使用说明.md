# ToolCenter 正式开发版

双击 `ToolCenter.exe` 即可打开 ToolCenter。该目录是项目唯一正式交付目录，后续更新会覆盖同名程序，不会新增按版本号命名的文件夹。

## 内置插件

- 音频设备切换：查看并切换 Windows 默认音频输出设备；
- HDR 开关：在桌面小组件中选择目标显示器，查看并切换 Windows HDR 状态；
- 桌面便签：记录纯文本内容，并在便签内添加可勾选清单项；
- 番茄钟：提供可自定义的专注与休息倒计时，支持暂停、继续、重置、阶段切换和多实例独立保存；
- 市场行情：查看股票、外汇和数字资产价格，支持自选产品、折线图/K 线图切换、1 日/5 日/1 月范围，以及小/中/宽三种桌面组件尺寸。

系统能力首次使用时会显示权限说明。HDR 操作只影响小组件中当前选择的显示器。

桌面便签未锁定时，可以按住顶部区域移动，也可以像普通 Windows 窗口一样拖动四条边或四个角自由缩放。便签内容、清单、位置和自定义尺寸均保存在本机；锁定后不能移动或缩放。

番茄钟默认使用 25 分钟专注和 5 分钟休息。阶段完成后不会自动开始下一阶段，也不会发送系统通知；请在小组件中确认后手动开始。

市场行情使用 Twelve Data 与 Binance 的公开免费接口。公共演示数据可直接查看部分产品，更多 Twelve Data 产品需要在插件设置中填写用户自己的免费 API Key；凭据由 Windows 凭据管理器保存，不会写入项目文件。行情约每 60 秒刷新，仅供信息展示，不应作为下单依据。

## 插件开发

插件源码位于项目根目录的 `plugins/`。在项目根目录运行：

```powershell
.\toolcenter.cmd plugin-dev
```

插件校验和注册表生成通过后，会直接启动真实 ToolCenter 桌面应用进行联调。

## 更新正式程序

插件和启动器通过验收后，在项目根目录运行：

```powershell
.\toolcenter.cmd release-build
```

该命令会完成全量检查、构建并覆盖本目录中的 `ToolCenter.exe`、校验值和版本信息。

## 当前发布边界

当前文件是本机便携式正式开发版，尚未提供安装器、代码签名和自动更新。不要加载来源不明的插件源码；正式程序只包含随项目构建并通过校验的第一方插件。
